# CMS Editability Audit

## Overview
This audit identifies all visible editorial text blocks on the public website and their current sources (Sanity CMS, static content files, or autogenerated).

**Goal:** Every visible festival/event/page content must be editable in Sanity Studio or intentionally static UI copy.

**Last updated:** Final pre-handoff audit (May 11, 2026)

### Priority 2 (Important - Map page editability)
1. ~~**Map page title/subtitle**~~ - ✅ **FIXED** - Added titleHu/En, subtitleHu/En to venue schema
2. ~~**Festival map image**~~ - ✅ **FIXED** - Added mapImage to venue schema
3. ~~**"Hogyan juss el?" heading**~~ - ✅ **FIXED** - Added directionsHeadingHu/En to venue schema

### Production Fallback Safety - ✅ CONFIRMED
- **performerDetailsHu fallback**: Only used when no Sanity performer document exists at all (`!baseArtist`). If a performer exists in Sanity with empty members, no hardcoded members appear.
- **BASE.artists fallback**: Used to detect if a performer has a Sanity doc. Does not override intentionally empty Sanity fields.
- **Safe fallback behavior**: All fallbacks are conditional on the absence of Sanity data, not on empty Sanity fields.

### Priority 3 (Limitations - Not critical for handoff)
1. **Rich text support** - No bold/italic/links in long-form content - ⚠️ **LIMITATION** - Portable Text not implemented
2. **Camp page formatting** - All content rendered as bullets - ⚠️ **LIMITATION** - displayMode provides basic list/paragraph control only

## Static Content That Should Remain Static (UI Copy)

These are generic UI labels that can stay in static files:
- Navigation menu labels
- Button labels (Foglalás →, Book now →, etc.)
- Generic section headings
- Filter labels (All, Thursday, Friday, etc.)
- "Read more", "Back to performers"
- Footer copyright text
- Generic form labels

---

## Editorial Content That Must Be CMS-Editable

These must be editable in Sanity:
- Accommodation note
- Page descriptions (hero, body)
- Performer bios and band member lists
- Camp fees and program descriptions
- Map intro/title
- Program plan
- Festival-specific notices
- Hotel descriptions and prices
